# Bolt Back · C03

Native Lens Studio source package for a three-part spatial memory/placement exercise. This includes the saved scene, original TypeScript implementation and native regression scenarios, authored box/material assets, render metadata and the actual project manifest. It replaces the earlier status-only export.

**Source package with explicit dependency gaps; exact clean import/compile has not been verified.** Native Windows mouse Practice, drag/drop, wrong-placement feedback and Reset were observed in the original development project. That evidence does not prove a fresh restore, physical glasses behavior, learning effectiveness or organizer acceptance.

## Open the native project

1. Use an authorized Lens Studio **5.23.2 build 26081320** installation (the saved project version), targeting Spectacles. This package supplies no installer and accepts no terms or accounts on your behalf.
2. Make a working copy of this directory. Read `DEPENDENCIES.json` before opening. Restore the exact missing package archives and two template assets described below from separately authorized sources. Preserve the supplied filenames and adjacent `.meta` files; these retain the saved project's asset UUID mappings. A current package with the same name is not proof of the same bytes.
3. Open `native-project/BoltBack.esproj.esproj` in Lens Studio. The doubled extension is the actual saved filename; it has not been renamed or edited for this export. Allow the editor to generate its normal local caches/support files.
4. Confirm package references resolve and compile without errors. Test Study → Practice → matching placements → Complete → Reset, wrong placements, release outside bounds and Windows mouse controls. Run the four native scenario classes (Study, Placement, Bounds and Mouse) using the restored LEAF integration. These export/import checks remain pending.
5. Validate the physical Spectacles interaction separately before any device-readiness or submission claim.
