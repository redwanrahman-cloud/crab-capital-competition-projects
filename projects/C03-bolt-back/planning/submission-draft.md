## Description

Bolt Back is a spatial reassembly exercise built for the Spectacles Lens Studio preview. Learners study three numbered virtual parts in their sockets, start Practice, and return each part from a tray to its matching position. A correct placement locks and advances the count; a wrong placement does not. Completing all three shows a Complete state, and Reset returns the exercise to Study.

The virtual panel and nearby feedback keep the exercise focused on remembering an arrangement. The prop is abstract: it does not recognize real equipment, teach a real repair, or establish learning or safety outcomes.

In the recorded local Windows preview run, mouse input demonstrated Practice, a rejected wrong drop, a correct placement, Reset from partial progress, three separate correct placements, a locked completed part, and Reset from Complete. Native TypeScript compilation and four LEAF preview scenarios succeeded in the final receipt. These results cover the editor preview; they do not demonstrate interaction or comfort on physical glasses. The editor uses project-controlled mouse release positioning while retaining the original placement validation; the result does not establish a physical-hand endpoint.
